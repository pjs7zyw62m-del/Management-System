# Live website updates
The browser polls the deployed same-origin blackcell-site-version.json every 30 seconds while visible. GitHub Pages/Jekyll renders the build revision or build timestamp. If the production host serves the template raw, increment the fallback value with every future release. No polling of unpublished commits.
The front page automatically refreshes when idle, other workspaces ask Update Now / Later so users can finish uploads and save work. The updater keeps the exact browser URL and valid auth session, restores window scroll and identified scroll containers best-effort. No passwords, account info or drafts are persisted. Dynamic UI without URL state is not restored. Apps can use BLACKCELL_LIVE_UPDATE.hold(reason) (returns release function) to explicitly block reload during async work and clean(element) once edits are saved. The animation is indeterminate. Browser and deployment testing are required.
