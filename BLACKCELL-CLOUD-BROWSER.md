# Cloud Browser pilot
Provider: Browserbase (managed Chromium live view). Supabase Edge Function blackcell-cloud-browser checks Level 7 owner plus verified corporate session, reads BLACKCELL_BROWSERBASE_API_KEY and optional BLACKCELL_BROWSERBASE_PROJECT_ID from Edge Function Secrets. No provider key in GitHub. Cloud pilot: one outstanding reservation, four attempts per rolling 30 days, 600-second provider timeout. Session recording and logging requested off. No public sessions. Do not use sensitive credentials during pilot. Browserbase's remote navbar is used for navigation; third-party authentication, downloads, mobile typing, video/audio and full tab handling are not validated. Existing embedded browser remains available. Close window or End Session releases provider session best effort; timeout is fallback. Provider account and API key are required; no provider plan has been purchased. Test provider session and verify privacy, billing, policy and auth before expanding access.
